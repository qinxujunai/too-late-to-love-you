# 《来不及爱你》页面设计与内容依据

## 阅读顺序

先看片，再理解人物，之后理解创作决定，最后进入方法。首页只用片名、一句题眼和真实静帧，不把工具、分辨率或履历放在影片之前。

“逐镜细读”是学习场景，不是第二次营销：左侧原生播放器，右侧九段原生可展开章节。默认展开照片，点时间码在旁边重看。手机保留可见画面与阅读空间。两播放器互斥播放，避免双重音轨。无 JS 仍能观看、展开与阅读；时间码链接可打开原片对应时间。

制作过程用六个真实决定串起创作者的能力：从不完整开始、道具语义、动作与情绪交接、参考帧隐含姿态、镜头动机、结尾留白。两款公开技能和原始提示词位于下层。原话短引文与编辑观察显式区分。完整生产档案另页承接深读，避免首页变成未编辑的文档粘贴。

## 视觉

沿用主站系统黑体、黑白浅灰、蓝色动作、三档文字色。影片区黑底，让真实光色成为主角；正文留白，桌面文本行宽受控，手机标题不挤成碎行。禁止生成替代影像和装饰性动画。原生 details、video、链接与可见焦点承担交互，不引入运行时库。

用户最终要求不转码、不处理视频；站点副本与提供文件 SHA-256 相同。用户随后提供 H.264 版本，已原样替换，仍以真实播放验证为准。英文片名未定。创作者确认音乐许可并授权公开；不虚构录音演唱版本或使用完整歌词。原始交接资料留本地，不原样公开其内部指令。
